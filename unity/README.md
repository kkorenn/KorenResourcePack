# Unity Projects

- `current/` builds AssetBundles for the current ADOFAI target with Unity 6000.3.10f1.
- `legacy/` builds AssetBundles for the legacy r141 target with Unity 2022.3.62f2.

Each project keeps Unity's expected root layout (`Assets/`, `Packages/`, `ProjectSettings/`). Do not move files inside `Assets/` without their `.meta` files.
